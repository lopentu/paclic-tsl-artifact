## 4. Does naming the articulator redirect the model, or relabel what it saw?

the relabelling analysis, per model. **X** = the target-action text with the articulator named; **A** = the same event with it withheld (the articulator the model chose itself); **B** = that same withheld run's own report of the non-dominant hand. `manual` is the no-switch baseline (the cue names what the model picks anyway) and `face` is the positive control (the cue can redirect). The question is which of those two the non-dominant hand resembles.


$J(X,B)$ requires the withheld run to have actually filled the `non_dominant_hand` description field. A model that omits it would score $J(X,B)=0$ on every item and pass the $A{>}B$ test trivially, so items whose withheld run lacks the field are EXCLUDED from the $B$ columns and counted separately, rather than being scored as a maximal difference.
