## 2. The label-only null for the visual-null 'identical to real' column

`label only` predicts, for every item, the modal value the REAL run gave to that item's target articulator, and nothing else. It is the rate any articulator-conditioned process reproduces the real run at, so a degraded condition only shows label-driven scoring if it reaches that rate -- and only shows recovered item-level information if it reproduces the real run's OFF-MODAL items.
