# Naming Is Not Locating: Reproducibility Materials

This repository contains the code, annotations, model outputs, and derived analysis reports accompanying the PACLIC 2026 camera-ready paper

> Peng, Kai-Yang, Pin-Er Chen, and Shu-Kai Hsieh. *Naming Is Not Locating: A Cue-Ablation Case Study of Metalinguistic Judgments about Taiwan Sign Language in Two Vision–Language Models.* PACLIC 2026 camera-ready paper.

The study examines whether vision–language models (VLMs) attribute linguistic functions to specific observed actions in Taiwan Sign Language (TSL) discourse. For 55 annotated target actions, the models produce structured descriptions of visible form and five functional or semiotic ratings. A 2 × 2 design independently manipulates the availability of an utterance translation and a coarse target-articulator cue. Additional experiments examine responses to misleading cues, variation in video evidence, and decoding choices.

Qwen3-VL-8B-Instruct is evaluated with the full diagnostic suite. GLM-4.6V-Flash is evaluated with the complete cue ablation and the two articulator mis-cue conditions, with human form-description ratings for two ablation cells. Gemma 4 E4B and MiMo-VL-7B complete the four-cell ablation without human form-description ratings. The evidence for between-model adequacy comparisons is therefore limited to the two human-rated checkpoints.

## Reproduction of reported analyses

To regenerate analysis reports from the **released model outputs and reference annotations**, run the following commands from the repository root.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-core.txt
PYTHON=.venv/bin/python bash reproduce.sh
git status --short data/results
```

The `reproduce.sh` script executes the analysis and scoring pipeline and overwrites the corresponding reports in `data/results/`. This process does not require a GPU or source videos because it uses previously generated model responses. Most reports regenerate without content changes. Two `length_and_tie_checks.md` reports also contain frame counts derived directly from source clips. Without those clips, the analysis substitutes an explanatory note for the frame-count lines. The transcript in `data/results/qwen3vl_8b/metalinguistic_probe.md` is generated by `scripts/20_run_metalinguistic_probe.py` during model inference and is not rewritten by `reproduce.sh`.

**Recomputing analyses is distinct from reproducing model inference.** The source videos and Chinese subtitle translations are not redistributed. Repeating the translation-cued inference conditions requires supplying these materials, together with the original checkpoints and compatible software and hardware.

### Organization of model outputs

The `data/model_outputs/` directory is organized by model and experimental condition.

- `qwen3vl_8b/` contains the four cue-ablation cells for the primary two-clip input (`__combined__`) and the target-clip-only variant (`__ev1__` / `__ev2__`). Follow-up subdirectories include `visual_null/`, `temperature_t1/`, `miscue/`, `miscue_resting/`, `mediation/`, `wrongclip/`, `anchored/`, `metalinguistic_probe/`, and `handedness_probe/`.
- `qwen3vl_8b_altlist/` and `qwen3vl_8b_exclusive/` contain alternative response-inventory conditions.
- `glm46v_flash/` contains the four ablation cells and both mis-cue conditions.
- `gemma4_e4b/` and `mimo_vl_7b/` contain four-cell cue-ablation outputs.

Output records retain the model's raw response, the parsed JSON, its condition and input identifier, and its schema-validation results. For GLM-4.6V-Flash and MiMo-VL-7B, a small number of responses were normalized when they differed from the schema only in JSON types not specified in the prompt. The original verdict and unmodified raw response are preserved in `schema_valid_strict`, `schema_errors_strict`, and `raw_text`, with any converted fields recorded in `post_hoc_normalization` (see `scripts/35_normalize_type_only_errors.py`).

## Reproducing model inference

Inference requires the source videos, `ffmpeg`, and access to a GPU with approximately 24 GB of memory. Install the model dependencies and prepare the clips before running the relevant conditions.

```bash
.venv/bin/pip install -r requirements-model.txt
python scripts/01_fetch_source_videos.py --url-list data/sources.csv
python scripts/03b_cut_event_clips.py
python scripts/04_deidentify_subtitles.py --source clip_manifest
python scripts/07b_run_inference_events.py --mode grounded --clip-kind combined
```

The other ablation modes are `ablate_translation`, `ablate_channel`, and `ablate_both`. The target-clip-only conditions use `--clip-kind ev1` or `--clip-kind ev2`. To run a different model, select its configuration with `--config scripts/config/pipeline_config.<model>.yaml`.

The follow-up runners include script `19` for degraded video, `20` for text-only elicitation, `21` for handedness, `26` for mis-cues, `27` for text-only mediation, `28` for sampling at *T* = 1.0, `31` for substituted clips, and `32` for rubric anchoring. The main scored conditions use greedy decoding with one generation per item. The *T* = 1.0 draws use seeds indexed by clip, event, condition, and draw; bitwise identical results are not guaranteed across changes in libraries or hardware.

**Translation-cued conditions.** The `translation` column in `clip_manifest.csv` is intentionally empty. In the original experiments, the prompt used Chinese subtitles from the source program. Those subtitle texts are not included in the release. To reproduce an inference condition that includes translation, populate the relevant `translation` values with the subtitles corresponding to each analysis window. The runners raise an error if translation is required but missing. The articulator-only and uncued conditions do not require these values.

## Ethical considerations and scope

The study uses publicly accessible TSL videos. Source footage and subtitle translations are not redistributed. The repository contains source timestamps, derived annotations, and model outputs. Captions and identifying overlays were blurred before model inference, and human annotators are identified only by the pseudonymous codes `A01` and `A02`.

The analysis concerns the behavior of specific models on a limited sample. It does not assess the language abilities of the people depicted, and neither the source videos nor their inclusion in the study imply endorsement by the signers or publishers. Functional reference annotations were provided by two linguists who are not fluent TSL signers; they should not be treated as independently validated signer judgments.
