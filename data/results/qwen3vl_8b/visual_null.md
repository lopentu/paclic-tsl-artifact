# Visual-null baselines: what survives losing the video?

Model outputs `qwen3vl_8b`, clip kind `combined`, cue cell(s) `grounded`, `ablate_translation`, `ablate_channel`, `ablate_both`. Each degraded condition is compared against the main dataset's own run for the SAME item and cue cell, so the only difference is pixel content -- the prompt is byte-identical throughout, including under `none`, where it still refers to "this clip". Generated by `scripts/analyze_visual_null.py`.

All conditions, the real baseline included, are restricted to the **110 items present in every condition**, so no two columns are averaged over different events.

## 1. Did the model answer, and did it notice?

A refusal or hedge under `none` is a result, not a failed run: a model that declines to score a clip it was not shown is behaving better than one that scores it confidently. Both are counted.
